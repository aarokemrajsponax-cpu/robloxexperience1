Set it up once (10 minutes)

  1. Make the key. Creator Hub → Open Cloud → API Keys → Create API Key. Name it Owner Remote. Under Access Permissions choose messaging-service, pick Maison Noir, tick Publish. Then Add API System → universe-datastores, pick Maison Noir, tick Read Entry, Create Entry and Update Entry (this is how servers that open later catch up). Under Security add the IP 0.0.0.0/0. Save & Generate Key, then copy the key.
  2. Give it to GitHub. Your repository → Settings → Secrets and variables → Actions → New repository secret. Name: ROBLOX_OPEN_CLOUD_KEY. Paste the key. Add secret. (Secrets are never shown to anyone, even in a public repository.)
  3. Send from this page with one tap (optional): claude.ai → Settings → Connectors → add GitHub. This page then sends straight away; the first time it asks you to allow it.
  4. Try it. Join the game, choose ☄️ Meteor shower ON here, and send. Meteors should start falling in your server about half a minute later, and keep falling until you send 🧹 Every effect OFF.

Only someone who can write to your GitHub repository, or who holds your Open Cloud key, can send a command, and the game checks every command against its own list before doing anything. Keep the key secret: if it ever leaks, delete it in Creator Hub and make a new one.
